# Sky Take Out

飲食店向けデリバリーシステムの学習プロジェクトです。

Java、Spring Boot、MySQL、Redisを利用し、バックエンド開発技術の習得を目的として開発しています。

---

# プロジェクト概要

本プロジェクトは、飲食店のデリバリー業務を管理するためのWebアプリケーションです。

店舗管理者向けの管理システムを中心に開発しており、従業員管理、商品管理、注文管理などの機能を実装しています。

本プロジェクトを通じて以下の技術を学習しました。

* Java
* Spring Boot
* MySQL
* Redis
* Git / GitHub
* REST API
